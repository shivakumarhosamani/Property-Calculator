## Problem Statement

This is a Number Properties Calculator web application built using Java Servlets. The application allows users to input a positive number through an HTML form, and the Servlet then computes and displays the number's Square, Cube, and Square Root in a professional, formatted result card.

## Technologies Used

- Java (Jakarta EE 11 / Servlets)
- HTML5, CSS3 (Professional UI with Google Fonts)
- Apache Tomcat 11.0.4
- Eclipse IDE

## How to Run This Project

1. Clone this repository or download the ZIP.
2. Import the project into Eclipse as a **Dynamic Web Project**.
3. Add **Apache Tomcat 11** as the server runtime in Eclipse.
4. Right-click on the project → **Run As** → **Run on Server**.
5. Open your browser and go to: `http://localhost:8080/Problem59/index.html`

## Servlet Concept Practiced

This project practices the **doGet/doPost** request handling mechanism. It demonstrates how to retrieve user input using `request.getParameter()`, perform server-side logic and validation, and dynamically generate a professional HTML response using `PrintWriter`.
